# Copy as Markdown or open as text

**Copy as Markdown** puts the whole document on the clipboard. Headings become `#` lines, tables become pipe tables, footnotes become `[^1]` notes, and links keep their URL. Images become placeholder links such as `![](#image-1)`, so the text stays small.

**Open as Text** opens the plain text in a new untitled editor. Tables come out with tabs between cells.

Both commands are also in the Explorer context menu for `.docx` files, so you don't have to open the preview first.
